# Diccionario de datos

El [diagrama entidad-relación](diagrama-entidad-relacion.md) contiene las entidades y relaciones conceptuales. Los campos propuestos para algunas entidades están en las secciones 7 a 10 del [README principal](../../README.md).

Este diccionario se completará cuando cada módulo defina sus tablas y migraciones. Por cada campo habrá que registrar tipo, nulabilidad, restricciones, índices y reglas de acceso por `negocio_id`.
