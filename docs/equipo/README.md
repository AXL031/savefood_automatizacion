1. Leer [responsabilidades](responsabilidades.md) y elegir un ID de tarea.
2. Consultar [dependencias](dependencias.md) y el registro del proveedor.
3. Abrir la guía local desde [mapa de carpetas](mapa-carpetas.md).
4. Actualizar [avances](avances/README.md) al finalizar cada entrega significativa.
