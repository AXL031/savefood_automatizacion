# Base de datos

> Guía vigente: [GUIA_DESARROLLO.md](GUIA_DESARROLLO.md). Responsable de coordinación: **Axel Cueva**. Tareas, dependencias y avances se detallan en la guía local.

Modelo entidad-relación, [diccionario de datos](diccionario-de-datos.md) y [esquema objetivo](esquema-objetivo-mvp.md) para el prototipo universitario local. Solo `negocio` y `usuario` pertenecen a la migración inicial; las entidades operativas aún no tienen migración ni implementación. El ER incluye el recorrido demostrable de pronóstico, plan, pedidos, automatizaciones y promoción sugerida. Recepción física y activación de descuentos son posteriores.

Aquí se conserva y actualiza la documentación de esta área.
