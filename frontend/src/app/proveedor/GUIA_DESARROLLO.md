# Respuesta pública del proveedor

Aguirre es dueño del dominio; Cueva coordina acceso público. Leer contrato-operacion-integrada.md. Ruta /proveedor/pedido/[token], sin sesión interna ni navegación administrativa. Token es autorización restringida, no identidad oficial; no pedir DNI. No aceptar al abrir GET. POST explícito confirma/rechaza; plazo real de una hora. No cachear ni filtrar token a sitios externos. El servidor es autoridad de expiración y repetición.
