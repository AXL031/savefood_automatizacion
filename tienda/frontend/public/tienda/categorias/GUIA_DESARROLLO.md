# Guía — Tienda independiente / categorias

Recursos y rutas de la tienda; conservar archivos e imágenes del prototipo de Rojas.
No dependencias ni imports de FoodSave; integración solo mediante API HTTP.
Leer [guía del proyecto](../../../../../tienda/GUIA_DESARROLLO.md) y
[contrato Payme](../../../../../docs/api/contrato-payme-pruebas.md).
Verificar imágenes/rutas en build y navegador; no presentar datos de ejemplo como
inventario real. Actualizar [avance de Cueva](../../../../../docs/equipo/avances/cueva.md)
al cerrar una entrega coordinada. Secretos y pagos reales no pertenecen a assets.
